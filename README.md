# TZONE Classroom

Nền tảng học trực tuyến TZONE (online course platform).

**Repository:** https://github.com/MinhtenlaNhi/TZONE-Classroom

## Project Structure

- `client`: React frontend (Vite)
- `server`: Node.js + Express backend
- `database`: DB connection and seed data
- `docs`: API docs and ERD notes

## Quick Start

```bash
npm run install:all
npm run dev
```

Default ports:
- Frontend: `5173`
- Backend: `5000`
